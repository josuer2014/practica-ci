# Práctica de Integración Continua

Proyecto realizado para practicar el uso de Git, GitHub y un proceso básico de Integración Continua.

## Descripción

El proyecto contiene una función sencilla desarrollada con Node.js que muestra un mensaje de bienvenida.

## Tecnologías utilizadas

- Node.js
- JavaScript
- Git
- GitHub
- GitHub Actions
- Visual Studio Code

## Ejecución

Para ejecutar el proyecto se utiliza el siguiente comando:

node app.js

## Pruebas

El proyecto cuenta con pruebas automáticas para verificar el funcionamiento de las funciones principales.

Para ejecutar las pruebas se utiliza:

node test.js

## Integración Continua

El proyecto utilizará GitHub Actions para ejecutar automáticamente las validaciones cada vez que se realicen cambios en el repositorio.
